# 積木編輯器操作說明

積木編輯器把一個程式顯示成可以拖放的積木。**積木（`.acblk`）是唯一的真相**，它產生的組譯檔（預設 `NAME.generated.asm`）會跟著更新；
建置、除錯、中斷點都照常使用產生的檔案。想先動手練習：`sample/13_block_editor`。

## 1. 開啟與轉換

| 想做的事 | 做法 |
|---|---|
| 開已有的積木程式 | 專案樹「積木」群組雙擊；或 File → Block Program → Open Block Program |
| 新的空白積木程式 | File → Block Program → New Empty Block Program（先有一個空的 Main） |
| 把目前的 `.asm` 變成積木 | File → Block Program → Show Current File as Blocks（Ctrl+Alt+B，工具列也有按鈕）。看不懂的行會**原樣保留成灰色「assembler text」積木**，不會失敗。原檔先備份成 `NAME.asm.bak`；第一次編輯積木後，這個 `.asm` 才變成「產生的檔案」，專案與所有 `.include` 都不必改 |
| 離開積木 | File → Block Program → Convert to Text (Detach)：產生檔變回一般文字（去掉產生檔頭並存檔），積木程式留在磁碟但離開專案 |

只是**開啟**積木程式不會改任何檔案。

## 2. 畫布

- 每個程式部分由一個**帽子**開頭：Definitions（定義）、Main、Peri；帽子上的數字是**產生順序**（由上到下、同高度由左到右）。
- 指令是上下相接的方塊；**指令的每個部分是元件**（數字、區域如 `scratchpad 0 to 1`、`ALU A`、運算、選項）插進它左右的插槽。形狀不合放不進去。
- **漂浮積木**（沒有接在任何帽子下）**不屬於程式**，不會被產生；狀態列會算出「N 串浮動積木」。這是放備用零件的地方。
- 右上角的 ⚠ 是警告、✖ 是錯誤；把游標停在上面看原因（組譯器的訊息會顯示在產生那一行的積木上，並帶 `asmc --explain` 的修法）。
- 滾輪縮放；工具列「Fit」全部看到、「1:1」回到 100%、「Tidy」整理排版（把各串積木排整齊，不改變程式順序）。
- 上方的 Blocks／Assembly code 切換產生的文字；在文字頁點一行會選到產生它的積木。

## 3. 編輯

| 動作 | 操作 |
|---|---|
| 改欄位 | **雙擊**積木上的欄位（或選取積木後 Enter／F2）；Enter 確定、Esc 取消、Tab 到下一個欄位、點別處也會確定。有選項的欄位可從清單選 |
| 選取 | 點一下；Ctrl＋點加選；在空白處**框選**；Ctrl+A 全選；方向鍵移動選取 |
| 拖動 | 拖積木＝帶著它**以下的整串**一起走；放到綠色高亮的接點就接上，**紅色斜紋**表示放不進去（會說明原因）；放在空白處＝漂浮；拖到一半按 Esc 取消 |
| 抽出再放回 | 把插槽裡的元件拖出來，原處留下**黑色空洞**；把適合的元件拖回空洞（積木會彈性撐開）。放進已被佔用的插槽：原本的元件彈出成漂浮，不會丟失 |
| 複製／剪下／貼上 | Ctrl+C／X／V（也能貼到文字編輯器，或把組譯器文字貼成積木）；Ctrl+D 就地複製 |
| 刪除 | Delete；Ctrl+Z 復原、Ctrl+Shift+Z 重做（Windows 也可用 Ctrl+Y；多步） |
| 停用／折疊 | Ctrl+E 停用（產生的文字變成註解）；右鍵 → Fold 折疊容器 |
| 註解 | **雙擊積木尾端**，打字；多行註解會讓積木與它外面的容器一起長高 |
| 右鍵選單 | 編輯、註解、剪下／複製／貼上／複製、**將選取的積木存成新積木…**、停用、折疊、刪除、整理 |

## 4. 工具箱與 Typeblock

- **工具箱**（左側，可用「Toolbox」按鈕收起）：範式、五個指令抽屜、結構、定義、文字，以及四個元件抽屜；上方搜尋框即時過濾。**拖**到畫布，或**雙擊／Enter** 接在選取的積木後面。每個抽屜標題的 **＋**（或右鍵 →「新增積木…」）可以加上**自己的積木**，並可由選取的積木存成新積木；自己的積木以斜體加 ★ 顯示，存在設定檔裡，下次還在。
- **硬體抽屜**（專案有硬體描述 `.achw` 時，緊接在「範式」後面）：描述裡每個元件自動有專屬積木，**名稱已經填好**，拖出來就能用；描述一改（不必存檔）抽屜立刻跟著變，專案沒有描述時就沒有這些抽屜。
  - **Hardware CSR**：每個 CSR 有 `write`／`set bits`／`clear bits`（action 與 ram／value 種類）和 `read`（除 action 之外）；唯讀的 status／const 只有 `read`。
  - **Hardware Devices**：每個在 DeviceMap 的裝置有 `read`、`read (several bytes)`、`write`（Peri），用它的 DeviceMap 名稱（如 `DEV_IMU`）。
  - **Hardware Services**：每個服務有 `publish`（Peri，長度取服務宣告的長度）。
  - **Hardware Data**：每個 `.const` 有 `load`（把常數池搬進暫存區，長度依內容）。
  - **Hardware Names**：每個 `.equ` 名稱是一個可以插進任何數字插槽的元件。
  - 滑鼠停在積木上看說明（位址、種類、描述）；Typeblock 也能用部件名稱找到它們（打 `AE_CTRL` 就列出它的四個積木）。每個積木產生的那一行都測試過能用該描述產生的定義組譯。
- **Typeblock**：在畫布上**直接打字**（或 Ctrl+Space）：打積木名稱，或**一整行組譯器**（`ALU ADD unsigned`、`start:`、`.equ X = 1`），Enter 插入；↑↓／Tab 選候選、Esc 取消。有選取的指令就接在它下面，所以**一行一行連續打就是整個程式**（只靠鍵盤可以打出 `01_hello_csr`）。
- **變數與運算式**：Variables 抽屜的 **set**／**change**，Expressions 抽屜的 **variable**／**calculation**／**comparison**。把 calculation 拖進 set 的值（占位的 0 會被換掉），再往裡面放 variable、數字。變數是暫存區的 2 位元組，位置自動挑、避開你手寫的位元組與 loop 計數。comparison 插進 if／while／wait until 的 **test** 就不必自己放 ALU 比較。
- **if／while／wait until**（Control 抽屜，只在 Main）：if 有 then／else 兩個槽；while 有 cond（算條件）與 body；wait until 有 cond。條件預設 `ALU_CMP_TRUE`，要在它**前面**放 ALU 比較（`if`）或讓 cond 的最後一個積木是 ALU 運算（`while`／`wait until`），否則積木上會有 W506 提示。
- **loop**（Control 抽屜，只在 Main）：標題上的下拉選 `for`（再填「times」次數，選填「counter at」）或 `forever`；展開成暫存區計數的迴圈。計數器位置留空＝自動，巢狀迴圈互不覆蓋。

## 5. 工作區

| 項目 | 說明 |
|---|---|
| 不存檔也會被用到 | 每次編輯都把 `.acblk` 與產生的組譯檔放進工作區緩衝區：**建置、除錯立刻看到**；Ctrl+S／Save All 兩個一起寫；關分頁選「放棄」兩個都還原。超過 300 個積木的大程式在編輯停頓 250 毫秒後才寫（存檔、建置、關閉前會先寫） |
| 專案 | `.acproj` 以 `blocks = 檔名.acblk` 登記程式（可多個），產生檔是來源；第一次編輯時自動登記。專案樹「積木」群組列出它們，產生的來源以斜體標「（產生）」 |
| 產生檔唯讀 | 在文字編輯器開產生檔：上方橫幅「這個檔案由 X.acblk 產生」＋〔開啟積木〕；不能輸入、取代、註解、搬行，跨檔重新命名會改到它時也擋下。**除錯、中斷點、跳到定義、搜尋照常可用** |
| 狀態列 | 積木數；「N 串浮動積木」「N 行以文字保留」「N 個問題」都是連結，點一下選到並顯示它，再點跳到下一個 |
| 名稱 | 硬體描述（`.achw`）定義的 CSR、裝置、服務、常數會被認得；插槽的下拉清單列出可用的名稱 |

## 6. 疑難排解

| 現象 | 原因與做法 |
|---|---|
| 積木放不上去，出現紅色斜紋 | 把游標停在目標上看原因：型別不合、Main／Peri 不能混、RET 要在程序裡等。這些是一定錯的接法才會擋 |
| 某積木右上角 ⚠／✖ | 停上去看訊息；組譯器的錯誤要先**建置**才會出現，編輯後徽章會先消失（行號可能移動），下一次建置再回來 |
| 灰色「assembler text」積木 | 積木還沒涵蓋這一行（`NAME EQU value`、新指令…）：**原樣保留**，照常組譯；狀態列點「N 行以文字保留」可跳過去 |
| 文字編輯器打不了字 | 這個檔案是由積木產生的：點橫幅的〔開啟積木〕；要改回文字用 Convert to Text (Detach) |
| 檔案打不開，顯示原因 | `.acblk` 壞了（JSON 錯誤）：橫幅會說在哪裡；用 `asmblk check 檔名.acblk` 看細節。原檔不會被改 |
| 想知道某積木對應哪一行 | 切到 Assembly code 頁，選取積木的那些行會被標示；反過來點行選積木 |
| 工具箱是空的／搜尋沒結果 | 清掉搜尋框；點「Toolbox」確認沒有收起 |
| 與舊版相容 | `.acblk` 的格式版本仍是 1，新的 `parts` 鍵只增不改：舊版 IDE 會忽略它、照文字欄位產生，結果相同；兩版交替編輯同一檔不會壞 |

## 7. 快速鍵

| 鍵 | 功能 |
|---|---|
| 雙擊／Enter／F2 | 編輯選取積木的欄位 |
| Tab／Shift+Tab | 編輯中跳到下／上一個欄位 |
| Esc | 取消編輯或拖曳；關閉 Typeblock |
| 方向鍵 | 移動選取 |
| 任何字母 | 開 Typeblock；Ctrl+Space 也可 |
| Ctrl+Z／Ctrl+Shift+Z | 復原／重做（Windows 另有 Ctrl+Y） |
| Ctrl+C／X／V／D | 複製／剪下／貼上／就地複製 |
| Ctrl+A／Delete | 全選／刪除 |
| Ctrl+E | 停用／啟用 |
| Ctrl+S／Ctrl+Shift+S | 存檔（積木與產生檔）／全部存檔 |
| Ctrl+Alt+B | 把目前的 `.asm` 顯示成積木 |
| 滾輪 | 縮放 |
