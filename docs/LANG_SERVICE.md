# 語言服務層（給編輯器與 IDE 用）

不依賴任何 UI 的純標準 C++，位於核心內，IDE 與日後的 LSP 伺服器共用。三個部分都**不需要組譯成功**，輸入到一半、有錯誤時仍可用。

| 部分 | 標頭 | 用途 |
|---|---|---|
| 診斷欄位範圍 | `asmcore.h` 的 `SrcLoc::col/endCol` | 波浪線標在正確的字上。預設標整條陳述（去掉標籤與註解）；訊息中有 `'符號'` 且出現在該行時縮到那個符號。0 表示未知 |
| 語彙與 token | `lang.h` | `Language::defaults(profile)` 給出所有助記符、指示字、區域、條件、子運算、具名參數（含簽名、說明、規格章節）；`tokenizeLine()` 把一行切成 token（上色用）；`cursorAt()` 回答「游標在哪個指令的第幾個運算元、已輸入的字首」（補全、參數提示用） |
| 索引與來源對應 | `index.h` | `Index::build()` 由 token 建立符號定義／參照（標籤、程序、`.equ`、`.csr`、`.service`、`.const`、`.devmap`），支援跳到定義、找參照、重新命名檢查、未定義符號；`SourceMap` 回答「這一行產生哪些位址（inline 展開會有多個）」「這個位址來自哪一行」「中斷點該移到哪一行」 |

## 規則

- 詞彙表由 `isa.h` 的同一份清單產生；規格改了不用兩邊同步。要加擴充詞彙：`Language::add(Entry)`。
- 範圍：標籤與程序名屬於 domain（`.main`／`.peri`），`.proc` 內的標籤屬於該程序，其他定義是全域的；解析順序是「程序區域 → domain → 全域」。
- `.include`：把含入的檔案依 `.include` 的位置排在 `sources` 裡傳入（共用檔案放前面）；未存檔的編輯器緩衝區直接傳文字即可。
- 這一層**不做**型別或資料流判斷；那是組譯器的工作（`Result::diags`）。
