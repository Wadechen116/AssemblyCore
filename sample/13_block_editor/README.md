# 13_block_editor

用**積木編輯器**練習的小程式：`demo.acblk`（積木，唯一的真相）→ `demo.generated.asm`（它產生的組譯檔，專案組譯的就是它）。
打開專案後，在專案樹的「積木」群組雙擊 `demo.acblk`。

| 你會看到 | 說明 |
|---|---|
| **Definitions / Main** 兩個帽子 | `.include "defs.inc"` 在定義區；程式在 Main，帽子上的數字是產生順序 |
| 一個**灰色積木**「assembler text」 | 定義區的 `LIMIT EQU 5`（8051 風格常數）：積木還沒涵蓋的行，**原樣保留成文字**（Raw），不會失敗、不會遺失；狀態列會說「1 行以文字保留」，點它就跳過去 |
| 一個 **loop** 積木（for 5 次） | 本體是「計數器加步進」；展開後用暫存區 26…31 計數，跟 `01_hello_csr` 手寫的一樣 |
| 右邊一串**浮動積木** | 兩個 `set/clear CSR bits`：**不屬於程式**（沒有接在任何帽子下），產生的文字裡沒有它們；狀態列會說「1 串浮動積木」 |

## 試試看（照順序）
1. **看產生碼**：左上角切到「Assembly code」，點某一行，積木頁會選到產生那一行的積木；切回「Blocks」。
2. **改欄位**：雙擊 `write CSR` 的值 `0x01`，改成 `0x03`，Enter。到「Assembly code」頁看那一行變了；Ctrl+Z 還原。
3. **改 loop 的次數**：雙擊 loop 的 `times`（5），改成 8；或雙擊 `repeat` 的 `for` 選 `forever`（次數欄位會消失）。
4. **從工具箱拖**：展開「Math」抽屜，把 `calculate` 拖到 loop 的本體最後；綠色＝可以放、紅色斜紋＝不行（並說明原因）。放在空白處＝浮著不丟失。
5. **拖積木接起來**：把右邊浮動的第一個積木拖到 `jump to done` 上方，放開，它就成為程式的一部分；Ctrl+Z 取消。
6. **Typeblock**：點一下空白處，直接打 `jump`（Enter 插入「jump」積木），或打一整行 `MOV CONST(7, 2) -> MAIN_SCRATCHPAD[4..5]`（用「以組譯器插入」）；Ctrl+Space 也能叫出。
7. **做出錯誤**：把 loop 的 `counter at` 填 `40`，積木上出現 ✖ 並說明「0…26」；填 `26` 就好。把 `jump to done` 的目標改成不存在的名稱，**建置**後錯誤會直接標在那個積木上，懸停看修法。
8. **多選與複製**：框選兩個以上積木，右鍵 →「將選取的積木存成新積木…」取名，工具箱「範式」抽屜就多了一個你自己的積木。
9. **存檔**：Ctrl+S 同時寫 `demo.acblk` 和 `demo.generated.asm`（不存檔也會被建置／除錯用到）。在文字編輯器打開 `demo.generated.asm`：它是**唯讀**的，上方橫幅有〔開啟積木〕按鈕。
10. **離開積木**：File → Block Program → **Convert to Text (Detach)**：產生檔變回一般文字，積木離開專案。

> 建置與除錯照常：F5 的中斷點可以下在產生檔的行上（那一行屬於哪個積木，積木上會看得到）。
