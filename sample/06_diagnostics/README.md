# 06_diagnostics

這個專案**可以建置**，但 `warnings.asm` 故意觸發 31 個警告，涵蓋 W401–W517 幾乎全部的碼（除了 W403，它只在 softret 對 Peri 呼叫時出現）。
每個警告在原始碼該行的註解裡標了預期的碼。用來測試問題面板、波浪線、懸停、篩選、跳轉、資料流切換與 `suppress`。

## 試試看
1. 建置，問題面板應顯示 **0 errors、31 warnings**。依嚴重度／檔案篩選；雙擊一筆跳到該行。
2. 懸停在波浪線上看完整訊息（含修法提示）；命令列 `asmc --explain W514` 顯示說明與 v31 `E_*` 名稱。
3. **Build → Data-flow check → off**：資料流類的警告（W501–W511、W514–W517）全部消失，只剩 W401／W402／W404／W405／W410／W512／W513。切 **error**：W5xx 變成 **E5xx** 錯誤，建置失敗。
4. 專案設定加 `suppress = W501`（或在 IDE 的專案設定）→ 5 個 W501 消失。
5. 專案設定加 `werror = 1` → 任何警告都使建置失敗。
6. 逐一修掉一個警告，看問題面板即時少一筆：例如給 `never_called` 一個 `CALL`（W401 消失）、在 `start:` 前載入 ALU 運算元（W501 減少）。
7. `asmc --list-codes` 列出所有診斷碼與對應的 v31 名稱（`E_SENSOR_BYTE_ORDER` 等）。

## 注意
這些警告是「資料流／契約」層級的；Debug 可以跑，但程式本身沒有意義。
